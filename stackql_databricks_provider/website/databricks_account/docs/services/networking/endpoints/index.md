## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[

>
<TabItem value="get">

Gets details of a specific network endpoint.

```sql
SELECT
name,
account_id,
endpoint_id,
display_name,
aws_vpc_endpoint_info,
azure_private_endpoint_info,
create_time,
gcp_psc_endpoint_info,
region,
state,
use_case
FROM databricks_account.networking.endpoints
WHERE account_id = '{{ account_id }}' -- required
AND endpoint_id = '{{ endpoint_id }}' -- required
AND account_host = '{{ account_host }}' -- required
;
```
</TabItem>
<TabItem value="list">

Lists all network connectivity endpoints for the account.

```sql
SELECT
name,
account_id,
endpoint_id,
display_name,
aws_vpc_endpoint_info,
azure_private_endpoint_info,
create_time,
gcp_psc_endpoint_info,
region,
state,
use_case
FROM databricks_account.networking.endpoints
WHERE account_id = '{{ account_id }}' -- required
AND account_host = '{{ account_host }}' -- required
AND page_size = '{{ page_size }}'
AND page_token = '{{ page_token }}'
;
```
</TabItem>
</Tabs>
